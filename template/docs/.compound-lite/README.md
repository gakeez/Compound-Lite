# .compound-lite

Local Compound Lite helper files.

This directory is for human-facing temporary HTML editors and read-only HTML
views. It is not an Agent source of truth.

Use Markdown artifacts as durable context:

- `STRATEGY.md`
- `docs/ideation/`
- `docs/brainstorms/`
- `docs/designs/`
- `docs/plans/`
- `docs/solutions/`
- `docs/evals/`
- `docs/pulse-reports/`

Generated HTML and JSON files under this directory can be recreated and should
not replace Markdown artifacts.
