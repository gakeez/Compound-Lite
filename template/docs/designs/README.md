# Design Artifacts

Store UX/UI design artifacts here.

Use this folder for:

- User journeys and flow decisions.
- Screen and state design.
- Interaction rules and copy rules.
- Accessibility and responsive notes.
- Image concept directions and accepted visual constraints.
- Handoff notes for `cl-plan`.

Design artifacts should be created by `cl-design` after confirmed requirements
and reviewed by `cl-review` before implementation planning.
