# Project discovery

Use discovery-first, thin adapters. Do not prescribe a technology stack before reading project evidence.

Read, when relevant:

1. AGENTS.md and any nested overrides.
2. STRATEGY.md for product/Agent context.
3. README and local docs.
4. CI configuration.
5. Manifest, lockfile, and config files.
6. Similar source files.
7. Similar tests.
8. Existing docs/ideation, docs/brainstorms, docs/plans, docs/solutions, docs/evals.

Summarize only what affects the current task. Do not dump the repository map.
