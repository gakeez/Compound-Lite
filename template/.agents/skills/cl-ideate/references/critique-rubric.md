# Critique rubric

For each idea, evaluate:

- User value: What user problem gets better?
- Strategy fit: How does it support STRATEGY.md?
- Evidence: What observation, user behavior, or reasoning supports it?
- Carrying cost: What will this add to maintenance burden?
- Smallest useful version: What is the smallest version that proves the idea?
- Failure case: Why might this be wrong?
- Agent risk: Does this change context, tools, autonomy, memory, or eval requirements?

Reject ideas that are impressive but not useful, broad but unfocused, or likely to create process/product debt.
