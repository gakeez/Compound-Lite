# Idea frames

Use several frames to avoid obvious suggestions.

1. User pain and friction.
2. Inversion: remove, reverse, or automate a painful step.
3. Assumption-breaking: what is treated as fixed but is actually a choice?
4. Leverage: what makes many future moves cheaper?
5. Agent-native improvement: context, tool use, memory, evals, recovery.
6. Constraint flip: what if there were 10x users, one user, zero budget, or no human in the loop?
7. Risk reduction: what prevents future failure or confusion?
